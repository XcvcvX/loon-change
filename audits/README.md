## 记录原则

- 汇总文档用于按阶段查阅历史背景；批次报告是具体优化实现和验证范围的记录。
- 历史审计文件不参与 Loon 运行时加载，不应因为“较旧”而删除。
- 若某批代码后来被覆盖或撤销，保留原始审计记录以便追溯；当前行为以 `main` 上的脚本和自动化测试为准。
